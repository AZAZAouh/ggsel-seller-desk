# GGsel Seller Desk

Личный Telegram-бот и панель продавца для управления заказами GGsel. Python, SQLite и интерфейс на JavaScript. Бот связывает оплаченный заказ с карточкой CapCut у поставщика RoboticVN и хранит состояние выдачи между перезапусками.

- Владелец видит ход выдачи в одной редактируемой карточке Telegram.
- Покупатель получает данные и инструкции в чате заказа GGsel. Команда «АДМИНИСТРАТОР» вызывает продавца.
- Проверка отзывов за семь дней запускается ежедневно по времени Варшавы. Состояние купона хранится по номеру заказа.
- Панель показывает статистику, расходы и календарь доступности средств. Даты из кабинета импортируются через интерфейс.

## Запуск на Linux с Docker Compose

1. Распакуйте проект. В каталоге с compose.yaml выполните `cp .env.example .env`, заполните пять полей и ограничьте доступ командой `chmod 600 .env`. Для рабочего экземпляра нужен токен @AZAZAggselbot. В коде проверяется имя бота.
2. При переносе действующего магазина сначала остановите старый процесс бота. Скопируйте каталог data в новый проект по защищённому каналу после остановки всех процессов, пишущих в него. Там находится история отправленных купонов, выдач и финансов. Сохраните резервную копию. Файл config/confirmed_availability.json из прежнего проекта переносит также вручную подтверждённые даты.
3. Выполните `docker compose up -d --build`. Проверьте `docker compose logs --tail=30 bot dashboard`. Для запуска без Docker нужны Python 3.12+, curl в PATH и база часовых поясов. Команды для двух процессов: `python bot.py` и `python app_server.py`.
4. Панель привязана к 127.0.0.1:8766 на Linux-сервере. На своём компьютере откройте туннель командой `ssh -L 8766:127.0.0.1:8766 user@server`, затем откройте http://127.0.0.1:8766. Панель предназначена для личного доступа. Публичная авторизация Telegram Mini App ещё не подключена.
5. Закупки по умолчанию выключены. При включённой настройке купонов бот проверяет реальные отзывы и может отправлять сообщения покупателям сразу после запуска. Для просмотра портфолио достаточно исходников; для изолированной проверки используйте тесты.

Проверки: `python -m unittest -v` и `node test_reporting.cjs`. Node нужен только для проверки графиков. Для остановки сервисов: `docker compose down`.
